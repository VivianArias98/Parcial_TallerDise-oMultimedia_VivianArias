# Portafolio de Ingeniero/a en Multimedia

## Caso 2. Portafolio de ingeniero/a en multimedia

Diseña un portafolio personal para un ingeniero/a en multimedia.

**Objetivo:** Mostrar trabajos y contacto.

**Debe incluir:**

- Header con nombre y tagline.
- Sección "Sobre mí".
- Grid con tres proyectos.
- Formulario de contacto o links a redes.
- Footer con créditos.
- Animación en hover sobre los proyectos (zoom, opacidad o desplazamiento).
